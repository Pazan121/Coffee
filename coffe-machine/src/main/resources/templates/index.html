Програмний продукт «Кава-машина»

Система призначена для автоматизації купівлі гарячих напоїв. Споживач може переглядати напої, додавати їх у кошик, обирати складники, поповнювати рахунок і переглядати історію покупок.

Для споживача
перегляд напоїв, вибір кількості, складників і місця отримання.
Для адміністратора
керування напоями, порціями, складниками, користувачами й замовленнями.
Контроль системи
перевірка балансу, залишків напоїв і доступності складників.
